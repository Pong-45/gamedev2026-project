# Lab6 — The Ember Hall

ฉากเริ่มต้น: res://common_room/scenes/common_room.tscn
เปิดโปรเจกต์ Lab6 แล้วกด F6 เมื่อเปิดฉากนี้ หรือ F5 เพื่อเล่นโปรเจกต์

การควบคุม: WASD เดิน, เมาส์หมุนมอง, Esc ปล่อยเมาส์, คลิกซ้ายจับเมาส์อีกครั้ง

ห้องดันเจียนขนาด 20 × 20 เมตร มีโถงทางเข้า พื้น ผนัง เพดาน ซุ้มประตู เสา โต๊ะ เก้าอี้ หีบ ถัง ลัง ธง คบเพลิง และไฟโทนอุ่นพร้อมเงา ทางเดินกลางเชื่อมถึงทุกพื้นที่ ผู้เล่นเป็นมุมมองบุคคลที่หนึ่ง

ตัวละคร 5 จุด:
1. ต้อนรับ: Walk
2. มุมสังสรรค์และพักผ่อน: Silly Dancing
3. ฝึกซ้อม: Hurricane Kick
4. อบอุ่นร่างกาย: Jumping
5. ทางเข้า: Running

ใช้โมเดลและแอนิเมชันคู่เดิมจาก Movement แต่ละไฟล์มีโครงกระดูก 33 กระดูก ปรับ forward root motion ให้อยู่ประจำจุด ปรับระดับเท้าของท่าเดิน วิ่ง เต้น เตะ โดยคงการลอยตัวของท่ากระโดด คลิปทั้งหมดเล่นวน

โครงสร้าง:
- scenes/common_room.tscn: ฉากสำเร็จที่มีโหนดทั้งหมด เปิดแก้ตำแหน่งได้ใน editor
- scenes/common_room_source.tscn: ฉากต้นทางสำหรับสร้างห้องซ้ำ
- scripts/common_room.gd: จัดฉาก เริ่มแอนิเมชัน HUD และโหมดทดสอบ
- scripts/player.gd: CharacterBody3D และการควบคุม
- dungeon/: ทรัพยากรจาก Modular Dungeons Pack-glb
- characters/: ไฟล์ GLB แปลงจาก FBX ที่ผู้ใช้ให้มา พร้อม metadata ระดับเท้า
- tests/bake_room.gd: สร้างฉากสำเร็จใหม่จากต้นทาง (จะทับ common_room.tscn)

ทดสอบด้วย Godot:
--path <โฟลเดอร์ Lab6> -- --verify-room
ตรวจการยืนบนพื้น การเดินเส้นทางครบพื้นที่ การชนกำแพงและโต๊ะ กระดูกแอนิเมชันทั้ง 5 ตัว กล้อง และ Esc
เพิ่ม --visual-tour เพื่อบันทึกภาพแต่ละจุด (ต้องรันแบบมีหน้าต่าง)

ไฟล์ทรัพยากรต้นฉบับใน Game6 และไฟล์เดิมที่ไม่เกี่ยวข้องของ Lab6 ไม่ถูกแก้ไข

Running ใช้ช่วงต้น 18 เฟรมจากไฟล์เดิม แล้วเชื่อมกลับท่าเริ่มที่เฟรม 24 เพื่อวนในจุดเดิมโดยไม่มีช่วงกลิ้งตัว
